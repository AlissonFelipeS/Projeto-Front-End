# Projeto-Front-End
Portifólio Pessoal

Este projeto foi realizado na cadeira de *Desenvolvimento Front-End* no curso de Análise e Desenvolvimento de Sistemas na Unipê.
Desenvolvendo um projeto pessoal, usamos das linguagens de marcação HTML e CSS, juntamente com a linguagem de programação JavaScript para criar um portifólio sobre a minha trajetória profissional.

Usamos na construção  para melhor entendimento do HTML a divisória do codigo por seções, também como a estrutura padrão da linguagem. 
Em conjunto usamos o bootstrap com intuito da página ficar melhor alinhada possível para qualquer dispositivo, usando conteiners junto com o grid-system.
Estilizamos toda a página com o css com o perfil de preto e amarelo.
Usamos o JavaScript para controle de tema e validação do formulário de contato
